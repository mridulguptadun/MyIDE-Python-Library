# MyIDE Python Library

A public collection of Python coding questions and runnable examples for **MyIDE Code Builder**.

## Language policy

All questions, titles, explanations, source code comments, and expected-output descriptions in this repository are written in English.

## Example format

Each question is stored as a JSON file with these fields:

- `id`: stable unique identifier
- `title`: short example title
- `topic`: subject category
- `difficulty`: Beginner, Intermediate, or Advanced
- `question`: task description in English
- `code`: runnable Python source code
- `expected_output`: sample output, including sample inputs when needed
- `explanation`: short English explanation
- `validation`: review status

## Repository layout

- `catalog.json` — metadata catalog for search and filtering in MyIDE
- `python/basics/` — introductory examples
- `python/conditions/` — conditional logic
- `python/loops/` — loop examples

## Safety

Code from this public repository should be shown for review first. MyIDE must run an example only after the user explicitly chooses to run it.

## Current coverage

This is the initial starter batch. More examples should be added in small batches and tested before being marked as validated.
